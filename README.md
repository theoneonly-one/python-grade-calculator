# Python Grade Calculator

## About

A beginner-friendly Python project that calculates a student's total marks, average marks, and grade.

## Features

* Accepts marks for Python, SQL, and Mathematics.
* Calculates total marks.
* Calculates average marks.
* Assigns a grade based on the average.

## Technologies Used

* Python

## How to Run

1. Install Python.
2. Open the terminal in the project folder.
3. Run:

```bash
python grade_calculator.py
```

4. Enter your marks when prompted.
